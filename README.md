# 🌱 Commonspace Idea Garden

### A shared space for ideas to grow.

Welcome to the **Commonspace Idea Garden** — a collaborative project by Commonspace Collective where ideas are shared, explored, and turned into something real.

You don't need to be an expert developer to participate. Bring your curiosity, creativity, and willingness to learn.

## 💡 What is this project?

Idea Garden is a place to discover interesting ideas, suggest new projects, and find ways to collaborate with others.

Our goal is to make sharing ideas feel welcoming, simple, and accessible to everyone.

## 🎯 Our goals

- Make it easy to share creative project ideas.
- Help people discover ideas they want to work on.
- Encourage collaboration between different skills and interests.
- Give beginners a friendly place to learn open-source contribution.
- Turn promising ideas into real projects over time.

## 🚧 Version 1

We're starting small and building in the open.

Our first version will focus on:

- A simple, welcoming website.
- A collection of project idea cards.
- Categories to help people explore ideas.
- A clear way to suggest new ideas through GitHub Issues.
- Contribution instructions for people who want to help.

No accounts or complicated setup required for our initial version.

## 🌟 How to participate

**Have an idea?**

[🌱 Submit a project idea](https://github.com/Commonspace-Collective/commonspace-idea-garden/issues/new?title=Project%20idea)

**Want to help build?**

[🛠️ Open a contribution issue](https://github.com/Commonspace-Collective/commonspace-idea-garden/issues/new?title=I%20want%20to%20contribute)

You can contribute through code, design, writing, testing, documentation, or thoughtful feedback.

## 🧑‍💻 Tech stack

Our initial website will use:

- HTML for structure.
- CSS for styling and responsive layouts.
- JavaScript for interactivity.

We'll keep the project beginner-friendly and add complexity only when we need it.

## 🤝 Contributing

1. Read the project README and contribution guidelines.
2. Open an issue or comment on an existing one before starting substantial work.
3. Explain what you'd like to contribute.
4. Make your changes in a branch or fork.
5. Open a pull request and describe your work.

Be kind, give constructive feedback, and remember that everyone starts somewhere.
